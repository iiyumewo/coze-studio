# 解析链路日志治理（待解决）

## 1. 状态

- 状态：待讨论，暂不实现
- 记录日期：2026-09-24
- 范围：聊天图片解析、聊天文件解析及其进入模型前后的日志

## 2. 问题背景

当前聊天附件解析链路会把内容转换为模型可读取的消息：

```text
图片 -> Base64 data URL -> 图片解析模型
文件 -> Parser -> 文本内容 -> Agent 模型输入
```

Coze 原生的 Eino callback 会记录模型和工具节点的输入输出。由于解析后的图片或文本已经成为普通模型消息，原生 callback 无法区分它们来自用户输入、文件解析、Skill 或其他工具。

当前风险主要是日志体积增长过快：

- 图片 Base64 被序列化到模型输入日志中，体积远大于图片本身；
- 文件解析后的正文可能达到数万字符，并在多个 callback 日志中重复出现；
- 同一份上下文可能同时出现在 `PreHandlerReq`、模型 callback 和工具 callback 中；
- Debug 日志中可能出现对象存储 URL 或其他不应长期保存的内容。

## 3. 已确认事实

1. `callback_reply_chunk.go` 的回调注册和事件转发属于 Coze 原生执行链，不能为了日志问题删除或改变。
2. 当前新增的 `chat_file_content_resolver.go` 只记录文件名、扩展名、文档数量和耗时相关信息，没有主动打印完整解析正文。
3. Base64 和大段文件正文主要是在进入原生 callback 后，被通用对象序列化日志记录。
4. 因此无法只在解析函数内部处理；需要在通用日志输出点做有限摘要，但不改执行行为。

## 4. 目标与非目标

### 目标

- 保留排障所需的 `log_id`、run/conversation/agent 标识、节点名、工具名、文件名、文件大小、耗时、Token usage、错误信息。
- 避免打印完整图片 Base64、完整文件正文和过大的工具输入输出。
- 为超大日志保留明确的截断标记和原始大小，方便判断是否发生截断。
- 不影响模型调用、工具调用、SSE 流式输出和数据库落库。

### 非目标

- 不重构 Coze 原生 callback 机制。
- 不建立完整的审计日志平台。
- 不扫描和改造全仓库所有历史日志。
- 不改变文件解析结果和模型上下文内容。

## 5. 推荐的最小方案

新增一个有限长度的日志摘要辅助函数，例如：

```go
conv.DebugJsonToStrLimit(value, 16*1024)
```

建议行为：

- 小于限制：按现有方式输出；
- 超过限制：输出前缀、`truncated=true` 和原始字节数；
- 图片消息：只保留 MIME、尺寸和字节数，不保留 Base64；
- 文件消息：只保留文件名、扩展名、URI 的非敏感摘要和内容长度；
- 工具调用：保留工具名、调用 ID 和参数键名，参数值遵循总长度限制。

第一阶段只处理以下高风险日志点：

- `backend/domain/agent/singleagent/internal/agentflow/callback_reply_chunk.go`
- `backend/domain/agent/singleagent/internal/agentflow/agent_flow_runner.go`
- `backend/application/conversation/openapi_agent_run.go`
- 解析链路相关的新增日志

对象存储实现、普通 SQL 日志和其他 Coze 原生日志暂不纳入本次范围。

## 6. 预估改动量

预计涉及 3～5 个 Go 文件：

- 1 个通用摘要辅助函数；
- 2～4 个高风险日志调用点；
- 2～3 组单元测试。

预计约 100～200 行代码，主要风险是确认摘要逻辑不会影响 callback 中实际传递的对象。摘要只用于日志参数，不应修改原对象。

## 7. 验收标准

- 一张图片的 Base64 不再出现在解析相关日志中；
- 大文件解析正文不会完整出现在单条日志中；
- 日志中仍能定位到 run、conversation、agent、节点、工具和文件；
- 超过限制的日志带有 `truncated` 和原始长度；
- 模型输出、工具调用、SSE 事件和历史消息内容与改造前一致；
- 解析失败时仍保留错误类型、文件扩展名和请求关联 ID。

## 8. 待讨论事项

- 默认单条日志上限采用 8 KiB、16 KiB 还是 32 KiB；
- 文件 URI 是否只保留 basename，还是保留 hash 后缀用于排查重复文件；
- 是否允许 Debug 模式通过显式开关临时查看有限长度正文；
- 是否需要为日志截断增加计数指标。
